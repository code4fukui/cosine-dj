# CosineDJ

[Tone.js](https://tonejs.github.io/) を使用して構築された、シンプルでブラウザベースのドラムマシンです。3つのシンセサイズされたドラム音源で8ステップのパターンを作成し、リアルタイムでオーディオエフェクトを適用できます。

## 機能

*   **パターンシーケンサー**: キック、ハイハット、スネアの3トラックで8ステップのシーケンスをプログラムできます。
*   **シンセサイズ音源**: すべてのドラム音は、Tone.jsのシンセサイザー（`MembraneSynth`、`MetalSynth`、`NoiseSynth`）を使用してリアルタイムに生成されます。
*   **リアルタイムエフェクト**: 調整可能なローパスフィルターとディストーションエフェクトを使用して、サウンドを変化させることができます。
*   **オートモジュレーション**: コサイン波を使用して、フィルターとディストーションのパラメーターを周期的に自動変調（モジュレーション）できます。これがCosineDJという名前の由来です。

## 使い方

1.  **パターンの設定**: 3x8グリッドのチェックボックスをクリックして、ビートをプログラムします。
    *   **上段**: キック
    *   **中段**: ハイハット
    *   **下段**: スネア
2.  **再生の開始**: `play` ボタンをクリックします。再生中、パターングリッドはロックされます。
3.  **エフェクトの調整**: スライダーを使用して、ローパスフィルターのカットオフ周波数とディストーションのかかり具合を変更します。
4.  **オートモジュレーションの有効化**: `filter auto` チェックボックスをオンにすると、フィルターとディストーションのパラメーターが時間経過とともに自動的に変化します。
5.  **再生の停止**: `stop` ボタンをクリックします。音声が停止し、パターングリッドのロックが解除されて編集可能になります。
